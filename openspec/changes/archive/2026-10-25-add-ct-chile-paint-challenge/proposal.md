# Proposal

## Why

Chile teams get a Paint station: `PUERTA.BMP` looks empty; flooding the background with the Fill With Color tool reveals a hidden message pointing to the concierge: `BUSCA A QUIEN CUIDA QUIÉN ENTRA Y QUIÉN SALE`, plus a bell drawing. First a short spike confirms Paint's fill works for this, otherwise a fallback reveals the message another way.

## What Changes

- Station `paint-puerta` for `chile`: while the session runs, `C:\My Documents\PUERTA.BMP` exists; it opens in Paint (BMP association). Removed when the session stops. During the session, Paint's File > Open dialog preselects the `24-bit Bitmap (*.bmp;*.dib)` type so `PUERTA.BMP` is listed immediately; the default is restored when the session stops.
- A generated asset `stations/assets/puerta.bmp` (24-bit, lossless): uniform near-white background, with the text and a doorbell drawn in a color indistinguishable by eye from the background (for example RGB 254,254,254 on 255,255,255). After the background is flooded with another color the message stands out. Generated by a one-off script that is not committed.
- No server, MSN or nginx change.

## Capabilities

## Impact

- **Layers**: app (station + asset, `src/apps/paint/challenge.js` + `paint-app.js` hook, `file-picker.js` option), tests, README.
- **Files**: `stations/chile-paint.js`, `stations/assets/puerta.bmp`, `registry.js`, `e2e/ct_station_chile_paint.spec.js`, README, `src/apps/paint/challenge.js`, `src/apps/paint/paint-app.js`, `src/shell/explorer/interface/file-picker.js`.
- **Persistence**: ZenFS only; the BMP is removed on finish. Edits the team saves over it are removed too.
- **EC2**: win98-web image only (adds an asset of a few hundred KB).

## Non-goals

- Changing Paint's tools; a hint system.
