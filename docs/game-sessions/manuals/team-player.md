# Team manual — Improving CT October

You have **60 minutes** to find the Y2K patch code and install the patch
before the system hits midnight. Everything you need is somewhere in the
game — inside this computer and outside of it.

## Starting

1. Double-click **Improving CT October** on the desktop (or Start >
   Programs > Improving CT October).
2. In the **Team** tab pick your **Office** and your **Team**, type your
   team's **Keyword**, and press **Start** (Enter works too).
3. If the keyword is wrong the field stays editable — fix it and try again.
4. A countdown appears on the right side of the desktop, starting at 60:00.
   Your session has begun — and the computer has changed. Look around.

## Playing

- Challenges live **inside** the Windows 98 environment — check the apps,
  files and places a normal user would look — and **outside** of it:
  the facilitators will point you to the physical part of the game.
- Every clue you solve brings you closer to the **Y2K patch code**.
- The moment your session started, the system quietly set things up for
  your office. When it ends, those things are gone — if you need to remember
  something, write it down on paper.

## Winning

1. When you think you have the code, open **Y2K Patch**.
2. Type the code and press **OK**.
3. If the code is right, the patch installs — the countdown stops and your
   time is recorded on the office board and podium.
4. If the code is wrong you get "The code was not accepted." — keep playing
   and try again. There is no penalty for a wrong code.
5. When the countdown reaches 00:00 it shows **Game over**. You can still
   enter the code after that — a correct code still finishes your run, but
   the result is recorded as over time.

## Good to know

- Y2K Patch refuses to work before your session is started — log in first.
- If your team is restarted or reset by the admin, your countdown and your
  session vanish: sign in and start again.
- **Start a new game** appears in the app after you finish — it hands the
  computer to the next team (your result stays on the board).
- Avoid: refreshing or closing the browser tab mid-run (your session lives
  in this tab), and changing system files you do not understand — the clues
  you need are meant to be found, but the machine underneath them is shared.
